Second version of cade: secrets kept out of the database, deletion of single events, a generation model under Apache-2.0 (Qwen3.5-2B), search by image description and ingestion in the background.

**Português:** segunda versão do cade: segredos fora do banco, exclusão de eventos isolados, um modelo de geração sob Apache-2.0 (Qwen3.5-2B), busca pela descrição de imagens e ingestão em segundo plano. As notas abaixo estão também no [CHANGELOG.pt-BR.md](https://github.com/Chipskein/cade/blob/v0.1.0/CHANGELOG.pt-BR.md).

## Install

- **Binary** (Linux x86-64, CPU, any CPU with AVX2): download `cade-v0.1.0-linux-amd64-cpu.tar.gz` below, check it with the `.sha256` file, and follow the [README](https://github.com/Chipskein/cade/blob/v0.1.0/README.md#install). The models are downloaded separately.
- **From source** (and for NVIDIA GPUs): the README's steps, now with `go tool mage` instead of `make` (#16).
- Then `cade init`, `cade doctor`, `cade ingest all`, `cade ask`.

## Before upgrading from v0.0.0

- **Migration 8 copies the database first.** It masks known secrets in stored events, deletes credential files (`.env*`, `*.pem`, `id_rsa*`…) and compacts the database. Before it runs, cade writes `cade.db.before-v8-<date>` (mode `600`) next to the database: **it takes about a minute and as much free disk as the database**. `cade doctor` tells, without changing anything, whether a migration is pending and whether it will copy. Migrations 9 and 10 only add a table and an index.
- **Run `cade reindex` once after migration 8.** Events whose text had a secret masked have no vectors until it finishes.
- **`ask --json` changed:** the task status `"concluida"` is now `"pr_aberto"`. It means local history saw the PR creation page, not that the PR was merged. Scripts that read the old code must change.
- **New generation model: run `go tool mage models` again.** The default is now Qwen3.5-2B, with its vision projector (`mmproj-Qwen3.5-2B-F16.gguf`, 0.67 GB). Configurations written by `cade init` with the old default switch to it by themselves, so `qwen2.5-3b-instruct-q4_k_m.gguf` can be deleted. An explicit `generation.model_path` keeps the model it names.
- **Images are described only with `sources.images` on.** It is off by default; `cade init` asks and shows the cost (about 1.7 s per image on an RTX 3060, 22 s on a 6-core CPU).
- **Do not re-import instead:** the Teams cache expires and Chrome keeps ~90 days of history, so `forget` + `ingest` loses data.

## Models and licenses

- cade is now under the **GPLv3 or later**; v0.0.0 stays under the GPLv2.
- The default generation model, Qwen3.5-2B, and its `mmproj` are under **Apache-2.0**. The non-commercial restriction of v0.0.0's Qwen2.5-3B no longer applies to the defaults.
- The binary's own dependencies are listed with their licenses in `THIRD_PARTY_NOTICES.md`, included in the archive.
