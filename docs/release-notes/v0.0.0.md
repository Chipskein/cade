First version of cade: a local, offline history of your git commits, browser history, files and Teams messages, queried by date or in natural language.

**Português:** primeira versão do cade: histórico local e offline dos seus commits, histórico do navegador, arquivos e mensagens do Teams, consultado por data ou em linguagem natural. As notas abaixo estão também no [CHANGELOG.pt-BR.md](https://github.com/Chipskein/cade/blob/v0.0.0/CHANGELOG.pt-BR.md).

## Install

- **Binary** (Linux x86-64, CPU, any CPU with AVX2): download `cade-v0.0.0-linux-amd64-cpu.tar.gz` below, check it with the `.sha256` file, and follow "Or from a release binary" in the [README](https://github.com/Chipskein/cade/blob/v0.0.0/README.md#install). The models are downloaded separately.
- **From source** (and for NVIDIA GPUs, `make cuda`): the README's steps from a clean clone to the first `cade ask`.
- Then `cade init`, `cade doctor`, `cade ingest all`, `cade ask`.

## Before upgrading a database from a development build

- **Migrations run by themselves** the first time a command opens the database. Before the first one that rewrites data, cade writes a copy next to it, `cade.db.before-vN-<date>` (mode `600`): **it takes about a minute and as much free disk as the database** (516 MB for a real history of 108 thousand events). `cade doctor` tells, without changing anything, whether a migration is pending and whether it will copy.
- **Run `cade reindex` once after migration 5** (vectors per chunk). Until it finishes, long texts have no vectors and `ask` warns about it; on a real history it took ~80 s on an RTX 3060.
- **Do not re-import instead:** the Teams cache expires and Chrome keeps ~90 days of history, so `forget` + `ingest` loses data.

For commercial use, get a license from Alibaba Cloud or switch to Qwen2.5-1.5B-Instruct (Apache-2.0), which reads questions worse (see the README's Models section).
