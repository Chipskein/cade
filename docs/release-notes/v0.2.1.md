cade runs beyond Linux: it builds from source on FreeBSD (CPU, or the GPU through Vulkan), and this release adds **experimental** archives for macOS on Apple Silicon and Windows x86-64. Nobody on the project has a Mac or a Windows machine: those two are built and tested only on GitHub's runners, so please report how they behave on a real one.

**Português:** o cade roda além do Linux: compila do código-fonte no FreeBSD (CPU, ou a GPU pelo Vulkan), e esta versão traz arquivos **experimentais** para macOS em Apple Silicon e Windows x86-64. Ninguém no projeto tem Mac nem Windows: esses dois são compilados e testados só nas máquinas do GitHub, então conte como eles se comportam numa de verdade. As notas abaixo estão também no [CHANGELOG.pt-BR.md](https://github.com/Chipskein/cade/blob/v0.2.1/CHANGELOG.pt-BR.md).

## Install

- **Linux x86-64** (CPU, any CPU with AVX2): `cade-v0.2.1-linux-amd64-cpu.tar.gz` below, checked with its `.sha256`, then the [README](https://github.com/Chipskein/cade/blob/v0.2.1/README.md#install). The models are the same as v0.2.0's.
- **macOS, Apple Silicon** (experimental): `cade-v0.2.1-darwin-arm64-metal.tar.gz`. It is not signed: run `xattr -d com.apple.quarantine cade` once. The models run on the CPU by default; `"gpu_layers": -1` tries Metal, which produced garbage on GitHub's virtual Macs. The config is `~/Library/Application Support/cade/config.json`.
- **Windows x86-64** (experimental, CPU): `cade-v0.2.1-windows-amd64-cpu.zip`, with `cade.exe` linked statically. It is not signed, so SmartScreen may warn. The config is `%APPDATA%\cade\config.json`, the database and models live in `%LOCALAPPDATA%\cade`, and `git` must be on the `PATH` for the git source.
- **FreeBSD and NVIDIA GPUs:** from source, as [DEVELOPMENT](https://github.com/Chipskein/cade/blob/v0.2.1/docs/DEVELOPMENT.md) explains (`go tool mage cpu`, `go tool mage vulkan` or `go tool mage build`).

## Before upgrading from v0.2.0

- **On Linux nothing changes:** no migration, no `reindex`, same models, config and `ask --json`.
- **macOS and Windows** are new installs: run `cade init`, then `cade doctor`.

## What is in it

- **FreeBSD** (#101): builds from source, CPU or Vulkan; tested on FreeBSD 15.1, where the retrieval suite matches Linux on the CPU.
- **macOS** (#53): Metal build, browsers under Application Support, background ingestion with throttled disk I/O.
- **Windows** (#54): paths stored with `/` like on Linux, data in AppData, browsers and the new Teams desktop app found by `cade init`, background ingestion with pause, stop and `--gentle` without signals, and the progress bar in the console.
- **Everywhere:** `go tool mage vulkan` for GPUs without CUDA, and two `doctor`/loading messages that were wrong.

See the [CHANGELOG](https://github.com/Chipskein/cade/blob/v0.2.1/CHANGELOG.md) for every change and measurement, and [PRIVACY](https://github.com/Chipskein/cade/blob/v0.2.1/PRIVACY.md) for where the files live on each system.
